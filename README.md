# ClubStack

ClubStack is a platform where users register an organization, customize it,
and get a tailored dashboard based on selected features. Organizations can
then invite or accept members to manage and participate in their club.

## MVP goals
- Organization registration and setup wizard
- Feature selection that configures the dashboard
- Member sign-up flow tied to an organization
- Roles: owner, admin, member

## Product flows
1. Organization owner signs up and creates an organization
2. Owner selects features (chat, announcements, shop, events, calendar, forum)
3. A custom dashboard is generated based on selected features
4. Members join the organization and interact with enabled features

## Initial feature modules
- Announcements
- Chat rooms
- Forum/discussions
- Calendar & events
- Shop/dues
