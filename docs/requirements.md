# Requirements

## Core personas
- Organization owner: creates and configures the org
- Admin: helps manage members and content
- Member: participates in the org

## Functional requirements
- Org registration with name, slug, and branding
- Feature selection to configure dashboard modules
- Dashboard renders only enabled modules per organization
- Member onboarding with invite link or approval
- Role-based access control
- Basic analytics for org activity

## Initial feature modules (from prior club app)
- Announcements
- Chat rooms
- Forum/discussions
- Calendar & events
- Shop/dues

## Non-functional requirements
- Secure auth and data isolation per organization
- Scalable to many organizations and members
- Mobile-friendly UI
